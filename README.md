# PLC Computer Training Center

This project is a React-based rewrite of the original PLC Computer WordPress theme, providing a modern, fast, and responsive user experience for the IT Training Center in Cambodia.

## Features

- **Modern Architecture**: Built with React, Vite, and Tailwind CSS.
- **Multilingual Support**: Supports both Khmer and English languages seamlessly.
- **Components**:
  - Hero Section & Promo Video
  - Course Grid & Details
  - Instructors & Alumni Showcases
  - Real-time Floating Chat Interface
  - Authentication (Student & Admin Portals)
- **State & Data**: Integrates with Firebase for robust back-end capabilities.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Build

```bash
# Build for production
npm run build
```
